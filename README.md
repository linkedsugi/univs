# 수업을 다시 쓰다 · 대경대학교 AI 워크북

대경대학교 「AI 시대의 수업과 평가」 교원 교육 워크북(2026.10.23 v4)을 수업 중 직접 작성하는 웹앱으로 구현했습니다. 정적 웹사이트로 동작하며 계정·API 키·데이터베이스가 필요하지 않습니다.

## 실행

Node.js 24 기준이며 설치할 npm 의존성은 없습니다.

```bash
npm run dev
```

기본 포트는 3000입니다. `PORT=8080 npm start`로 바꿀 수 있습니다. `npm run check`는 JavaScript 구문을 확인합니다.

실제 브라우저 검증은 서버 실행 후 `npm test`로 진행합니다. Python Playwright와 `/usr/bin/chromium`이 필요하며, 현재 클라우드 환경에는 제공됩니다. 검증 PDF·스크린샷은 `/tmp/univs-validation`에 생성합니다.

## 사용 흐름

1. p.1 과목·대표 과제 → p.2 AI 수행 분석 → p.3 학습 장면
2. p.4 AI 단계·제출물·이해 확인 → p.5 루브릭
3. p.6 학생 배포용 과제 안내문 → p.7 강의계획서 반영분 → p.8 완성 점검
4. 전체 워크북, 학생 배포용 안내문(평가표·기록 양식 포함), 강의계획서 중 범위를 골라 브라우저 인쇄 창에서 **PDF로 저장**

- ‘크게 쓰기’로 긴 입력창을 확대합니다. 확대 창과 원래 입력창이 함께 반영됩니다.
- 호텔외식조리·뷰티미용·공연예술 유형의 샘플은 수업 연습용이며 실제 학교 운영 기준이 아닙니다.
- 샘플 적용 직전 기록을 보관하며 ‘샘플 취소’로 돌아갑니다. ‘새로 작성’은 확인 후 모든 입력과 복원 기록을 지웁니다.
- p.6에 처음 들어가면 앞 단계의 입력을 바탕으로 안내문을 조합합니다. 직접 편집한 본문은 보존하며, 앞 단계를 변경했다면 ‘앞의 기록으로 다시 채우기’로 갱신합니다.
- p.7의 ‘대표 과제 정보를 첫 행에 가져오기’로 과제명·일정·AI 단계를 반영합니다. 루브릭 100점·평가 비율 100%·AI 단계 일치를 점검합니다.
- 빠진 정보는 `[확인 필요]`로 표시합니다. 확인 경고가 있어도 초안 PDF 저장은 가능합니다.
- p.6·p.7의 내용은 AI API 호출 없이 입력값으로 조합됩니다. 프롬프트 카드 복사는 별도로 이용하는 AI에 붙여 넣기 위한 기능입니다.

## 저장과 개인정보

입력 내용은 서버로 보내지 않고 해당 브라우저의 localStorage에 저장합니다. 공용 PC에서 작업을 마치면 JSON 또는 PDF로 보관한 후 ‘새로 작성’으로 삭제하세요. 브라우저 데이터 삭제·비공개 모드·저장 공간 제한 시 자동 저장이 보장되지 않으므로 JSON 백업을 권장합니다. JSON 백업에는 작성 내용과 샘플 적용 전 복원 기록이 포함됩니다. 시작 화면에서 백업을 불러올 수 있습니다.

다른 기기와 자동 동기화하지 않으며 여러 탭에서 동시에 편집하는 사용은 지원하지 않습니다. 외부 폰트·분석 도구를 사용하지 않습니다. PDF는 운영체제에 설치된 한글 글꼴로 출력됩니다. 인쇄 창에서 용지를 A4로 하고 머리글·바닥글을 끄면 더 깔끔합니다.

## GitHub Pages 배포

`.github/workflows/pages.yml`에 main 브랜치 자동 배포를 구성했습니다.

1. GitHub 저장소 Settings → Pages → Build and deployment → Source를 **GitHub Actions**로 지정합니다.
2. main에 푸시하거나 Actions에서 `Deploy workbook to GitHub Pages`를 실행합니다.
3. 배포 작업의 `github-pages` 환경에 표시되는 URL로 접속합니다.

프로젝트 경로 배포를 지원하도록 모든 리소스는 상대 경로로 연결했습니다. 커스텀 빌드나 유료 서비스가 필요하지 않습니다. 배포 산출물은 `index.html`, `app.js`, `data.js`, `style.css`, `favicon.svg` 5개뿐이며 테스트·원본 첨부파일·로컬 설정은 공개하지 않습니다. 다른 정적 호스팅에서도 이 5개 파일을 동일 폴더에 올리면 동작합니다.
